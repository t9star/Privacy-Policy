## 新しいアプリのポリシーを追加する手順

1. 本リポジトリに `<アプリ名>.html` を作成し、ポリシー内容を記述する（英語デフォルトまたは日英対応）。
2. `index.html` にアプリのカードリンクを追加する。
3. `git add .` -> `git commit -m "Add policy for <アプリ名>"` -> `git push` を実行する。
4. Google Play Console の「ポリシーとプログラム」＞「アプリのコンテンツ」＞「プライバシーポリシー」に `https://t9star.github.io/Privacy-Policy/<アプリ名>.html` を設定する。
